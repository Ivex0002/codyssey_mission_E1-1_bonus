# 환경 변수 활용

- 편의성을 위해 이전 코드를 재활용했습니다.

### 사용한 yml 파일
```
services:
  my-web-app-e1-1-bonus:
    build: .
    image: my-web
    ports:
      - "8080:8000"
    environment:
      - MODE=dev
      - DEBUG=true        # 테스트를 위해 2가지 env 설정을 추가했습니다
      - REDIS_HOST=cache  #
    volumes:
      - .:/app
    depends_on:
      - cache

  cache:
    image: redis:latest
    ports:
      - "6379:6379"
```
